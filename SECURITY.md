# Sicurezza e uso previsto

## Ambito

NAVIS è progettato per formazione e dimostrazione difensiva in locale. Non contiene funzioni per inviare comunicazioni, ospitare pagine di raccolta dati, acquisire credenziali o collegarsi a sistemi esterni.

## Dati

I progressi sono salvati in `localStorage`. L’utente può esportarli manualmente in JSON o cancellarli dalla schermata Rapporti. Non inserire nel sistema informazioni operative, personali, classificate o credenziali reali.

## Segnalazioni

Per segnalare una vulnerabilità, usare un canale privato del repository e includere versione, browser, passaggi di riproduzione e impatto. Non pubblicare dati sensibili in una issue pubblica.

## Hardening per impiego organizzativo

Prima di un uso reale, integrare il progetto nel processo di sicurezza dell’organizzazione, effettuare revisione del codice, configurare intestazioni sul server di destinazione e adattare contenuti, ruoli e contatti alle procedure autorizzate.
